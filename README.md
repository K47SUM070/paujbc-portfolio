# PauJBC · Portfolio

Portfolio personal de Juan Bautista Coria (PauJBC), con trabajos de desarrollo web, soporte IT, Linux y formación en ciberseguridad.

**Sitio:** [paujbc-portfolio.vercel.app](https://paujbc-portfolio.vercel.app)

## Tecnologías

React, Vite, JavaScript, HTML y CSS. Despliegue en Vercel.

## Trabajo realizado

- Desarrollo de una interfaz con identidad visual propia.
- Presentación de proyectos y servicios profesionales.
- Integración de contenido audiovisual y enlaces de contacto.

## Estructura

- `src/`: código de la aplicación y estilos.
- `public/`: recursos públicos.
- `vite.config.js`: configuración de Vite.
- `vercel.json`: configuración de despliegue.
